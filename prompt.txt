### Visual & UI Requirements (Glassmorphism + Animation Skills)
1. **Glassmorphic Layout System:**
   - Create a multi-layered atmospheric background (subtle animated mesh gradients / ambient glow orbs in dark mode with a crisp light-mode alternative) that gives translucent surfaces genuine depth to refract against.
   - Build a sticky glassmorphic top navigation bar (`backdrop-filter: blur(...)`, subtle 1px specular border highlights, layered shadows) with brand identity, quick-jump search trigger, theme toggle, and GitHub link.
   - Build a collapsible glassmorphic left sidebar for hierarchical documentation navigation (Getting Started, Core Concepts, Reactivity/State, Routing, Components, API Reference, Examples) and a floating right-hand "On This Page" table of contents with active-section scroll spy.
   - Ensure strict contrast and readability: keep body copy and code blocks high-contrast and legible while using frosted glass surfaces for cards, callouts, navigation chrome, and interactive sandboxes.

2. **Motion & Micro-interactions (Animation Skill):**
   - Implement smooth, purposeful entrance choreography (staggered fade + subtle upward translate) for hero elements, feature cards, and documentation sections.
   - Add fluid route/page transitions when navigating between documentation topics so the site feels like a native app.
   - Add tactile micro-interactions: hover light-sheen/border-glow tracking on glass cards, animated active-indicator pills in the sidebar and TOC, and smooth copy-to-clipboard feedback on code blocks.
   - Respect `prefers-reduced-motion: reduce` across all animations.
